# Web Arayüz Tasarımı (BDT249)

Dersin haftalık konu anlatımları: HTML, CSS, Flexbox, responsive tasarım ve Bootstrap tanıtımı.
Her sayfada kod örnekleri, tarayıcı ekran görüntüleri, tablolar ve konu sonu testi bulunur.
Sayfalar tarayıcıda açılır, kurulum gerektirmez.

**Site:** <https://alsnakty.github.io/lectures-kmyo/webkmyo/>

## Yerelde açmak

Depoyu indirip `webkmyo/index.html` dosyasına çift tıklamanız yeterlidir; internet
bağlantısı gerekmez.

## Klasör düzeni

```
index.html                  ana sayfa (haftalık plan)
*.html                      konu sayfaları
proje-yonergesi.html        dönem projesi yönergesi
css/ders.css                ortak stil
css/vendor/                 highlight.js teması (github-dark) ve lisansı
js/ders.js                  ortak betik
js/vendor/                  highlight.js (HTML, CSS, JavaScript) ve lisansı
images/                     ekran görüntüleri ve şemalar
```

Sayfalar saf HTML, CSS ve JavaScript ile yazılmıştır. Kod renklendirme için highlight.js'in
yerel kopyası kullanılır; yazı tipi indirmesi veya CDN çağrısı yoktur.
